## Söka publikationer

Publikationer kan sökas genom att använda sökrutan och olika filter som utgörs av textfält och rullistor. En sökning i sökrutan kan kombineras med ett eller flera filter. I alla textfält kan sökkommandona *AND* och *OR* användas för att justera sökningen. Gemensamt för samtliga textfält är att sökningen görs automatiskt medan man skriver.

De aktiva filter som valts visas ovanför träfflistan. De filter som är aktiva kan stängas var för sig eller via *Rensa filter*, sökningen uppdateras automatiskt när filter stängs.
